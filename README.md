# Aniket Kumar — Portfolio

My personal portfolio site, built to showcase my work as a Data Analyst.

🔗 **Live site:** [portfolio-website-psi-seven-56.vercel.app](https://portfolio-website-psi-seven-56.vercel.app/)

## About

I'm a Data Analyst with hands-on experience across data cleaning, exploratory analysis, dashboarding, and machine learning. This site is where I showcase my experience, projects, and skills.

## Built with

- Plain HTML, CSS, and JavaScript — no framework, no build step
- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Work Sans](https://fonts.google.com/specimen/Work+Sans), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts
- Hosted on [Vercel](https://vercel.com), deployed straight from this repo

## Structure

```
├── index.html   → the entire site (markup, styles, and script in one file)
├── profile.jpg  → profile photo used in the hero section
└── README.md    → this file
```

## Editing content

All editable content — projects, GitHub/LinkedIn links — lives inside the `<script>` tag near the bottom of `index.html`, clearly marked between:

```
EDIT BELOW THIS LINE TO UPDATE YOUR SITE
```
and
```
DO NOT EDIT BELOW THIS LINE
```

No build step or dependencies — just edit `index.html` directly on GitHub and commit. Vercel auto-redeploys on every push to `main`.
